# 💻 Portfólio — Ágatha Cristina Marinho da Costa

Portfólio pessoal desenvolvido como projeto acadêmico para praticar conceitos de **HTML, CSS e JavaScript**, apresentando informações sobre minha formação, habilidades, projetos e formas de contato.

O projeto também foi desenvolvido com foco em **organização do código, estrutura semântica, responsividade e interação com JavaScript**.

---

## 👩‍💻 Sobre o projeto

Este site apresenta meu perfil acadêmico e profissional como estudante de **Análise e Desenvolvimento de Sistemas na FATEC Sorocaba**.

A página foi estruturada para reunir, em um único lugar:

* Apresentação pessoal;
* Formação acadêmica;
* Cursos complementares;
* Habilidades técnicas;
* Soft skills;
* Projetos desenvolvidos;
* Links para redes profissionais;
* Formas de contato.

---

## 🎯 Objetivos

O projeto tem como principais objetivos:

* Praticar a estruturação de páginas utilizando HTML;
* Desenvolver layouts utilizando CSS;
* Aplicar conceitos de CSS Grid e Flexbox;
* Criar uma página responsiva para diferentes dispositivos;
* Utilizar JavaScript para adicionar interatividade;
* Praticar organização e manutenção de código;
* Criar um portfólio pessoal para apresentação acadêmica e profissional.

---

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para estruturar o conteúdo da página de forma semântica, incluindo:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<footer>`
* Tabelas;
* Listas;
* Links;
* Imagens;
* Metadados.

### CSS3

Utilizado para estilização e organização visual do site.

Principais recursos utilizados:

* CSS Grid;
* Flexbox;
* Variáveis CSS;
* Responsividade;
* Media Queries;
* Transições;
* Bordas arredondadas;
* Sombras;
* Organização por seções.

### JavaScript

Utilizado para implementar a troca de tema do site.

O botão permite alternar entre:

* 🌸 Tema claro;
* 💜 Tema escuro.

A troca é realizada utilizando manipulação de classes com `classList`.

---

## 🎨 Temas

O site possui dois temas:

### 🌸 Tema Lilás/Rosa

Utiliza tons de rosa claro, branco e roxo.

### 💜 Tema Escuro

Utiliza tons de roxo e rosa.

A alteração do tema é realizada através do botão presente no menu de navegação.

---

## 📱 Responsividade

O site foi desenvolvido para se adaptar a diferentes tamanhos de tela.

Foram utilizadas **Media Queries** para ajustar:

* Menu de navegação;
* Tamanho das imagens;
* Organização das seções;
* Cards;
* Tabelas;
* Habilidades;
* Links de contato.

O layout pode ser utilizado em:

* 💻 Computadores;
* 💻 Notebooks;
* 📱 Smartphones;
* 📱 Tablets.

## 📂 Estrutura do projeto


Arquivo responsável pela estrutura e conteúdo do site.

Arquivo responsável pela aparência, layout, cores, responsividade e animações.

### `app.js`

Arquivo responsável pela funcionalidade de troca de tema.

### `img/`

Diretório que contém as imagens utilizadas no site.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/agathacris231894-design/site-simples.git
```

### 2. Entre na pasta

```bash
cd site-simples
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

em seu navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para visualizar as alterações em tempo real.
